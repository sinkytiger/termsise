# 텀시세 · 공시로 만든 한국 벤처투자 조건 지도 (데모)

2026 AI 플랫폼 구축 경진대회 예선 기획서의 데모 페이지입니다.

- **투자조건 지도**: DART 감사보고서(2026.3~5 접수 비상장 외감법인) 중 무작위 6,619건에서 자사 우선주 조건이 적힌 207개사의 상환권·상환보장수익률·상환청구 시점·전환가 조정 조항 분포
- **내 조건 넣기**: 입력한 계약 조건의 공시 사례 내 위치와, 상대 투자자 유형·계약일에 따라 적용되는 벤처투자법 규칙(일반 정보). 입력값은 브라우저 밖으로 전송되지 않음
- 데이터: OpenDART(금융감독원), DIVA 조합현황(한국벤처캐피탈협회), 국가법령정보센터. 페이지에는 집계값만 들어 있음

이 페이지는 공시 통계와 일반 법률 정보를 보여주는 데모이며 법률 자문이 아닙니다.
